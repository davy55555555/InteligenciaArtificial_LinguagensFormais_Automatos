# Exercícios Comentados — Aulas 01 e 02

## Linguagens Formais, Alfabeto, Linguagens e Gramáticas

### 1. Alfabeto
Considere:
```text
Σ = {0,1}
```

Esse conjunto representa o alfabeto, isto é, os símbolos permitidos para construir cadeias.

### 2. Palavra
Uma palavra é uma sequência finita de símbolos do alfabeto.

Exemplo:
```text
abba ∈ Σ*
```

### 3. Linguagem formal
Uma linguagem formal é um conjunto de palavras.

### 4. Gramática formal
Uma gramática descreve como palavras são produzidas a partir de regras.

## Exercício para o estudante
Considere `Σ = {a,b,c}`.

Responda:
1. Quantos símbolos existem no alfabeto?
2. Quais são os símbolos?
3. O símbolo `a` pertence ao alfabeto?
4. O símbolo `d` pertence ao alfabeto?
5. Escreva uma palavra formada por símbolos desse alfabeto.

Resposta esperada:
- 3 símbolos: `a`, `b`, `c`
- `a` pertence ao alfabeto
- `d` não pertence ao alfabeto
- palavra: `babaca`
