# Exercícios Comentados — Aulas 01 e 02

## Linguagens Formais, Alfabeto, Linguagens e Gramáticas

### 1. Alfabeto
Um alfabeto é um conjunto finito de símbolos. Exemplo:
```text
Σ = {0,1}
```

A palavra `01` é uma sequência de símbolos desse alfabeto, mas `2` não é.

### 2. Palavra
Uma palavra é uma sequência finita de símbolos pertencentes ao alfabeto.

### 3. Linguagem formal
Uma linguagem formal é um conjunto de palavras sobre um alfabeto.

### 4. Gramática formal
Uma gramática gera palavras de uma linguagem a partir de regras de produção.

## Exercício para o estudante
Considere `Σ = {a,b,c}`.

Responda:
1. Quantos símbolos existem?
2. Quais são eles?
3. O símbolo `a` pertence ao alfabeto?
4. O símbolo `d` pertence ao alfabeto?
5. Escreva uma palavra formada por esses símbolos.

Exemplo de resposta:
- 3 símbolos: `a`, `b`, `c`
- `a` pertence
- `d` não pertence
- palavra: `babaca`
